First of all change the color setting to [[USB]].
![[Pasted image 20250114093744.png]]

  
Create three circles for your primary color: 
First circle with main color 
Second with a lighter color 
Third with a darker color
![[Pasted image 20250114095847.png]]

Now to rename the colors, select everything, and press Ctrl + R, in the {Rename to} field put {Primaria/} and press the Number button with the down arrow.
![[Pasted image 20250114100536.png]]

Styler Plugin => this plugin helps you insert colors from your palette into the color library, for this purpose: Select all elements from your palette, right click on the canvas, {Plugins}, {Styler}, {Generate Styles}.
![[Pasted image 20250114101708.png]]![[Pasted image 20250114102102.png]]
