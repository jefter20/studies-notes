#Class22 #StylerPlugin  #UIColorPalettePlugin #ColorPalette

Access the link below to view Material Design color content:
https://m2.material.io/design/color/the-color-system.html#color-theme-creation
  
To start, create an element, a circle for example, change the element's color to the main color of the project, rename the element's layer to FolderName/ColorName} using the shortcut Ctrl + R.
![[Pasted image 20250115031010.png]]

Now open the plugin (a plugin modal will open), click on the {Scale} tab, select the element with the main color, and within the modal click on {Create a UI Color Palette}.
![[Pasted image 20250115031917.png]]

Then the color palette is created.
![[Pasted image 20250115033846.png]]

To add the palette created by UI Color Palette to the color library, you need another Plugin, Styler, the plugin used in the last class. With it installed, in the left side menu select all color layers in the palette (900 to 50), and run {Generate Styles}.
![[Pasted image 20250115034036.png]]

Now it is possible to access the colors in the library.
![[Pasted image 20250115034653.png]]

To use the colors in the library, simply click on an element on the canvas, and in the right side menu, in {Fill} click on the button next to {Apply styles and variables}.
![[Pasted image 20250115035100.png]]

	KEYBOARD SHORTCUTS:
		Ctrl + Shift + Left mouse button => Collapses and uncollapses selected layers.
