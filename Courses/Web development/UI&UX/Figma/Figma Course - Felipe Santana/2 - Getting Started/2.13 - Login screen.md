##### **Making the logo**

First of all, activate the grid. Then use PenTool and also the geometric shape tools to build a logo. Use the tool [[Bend Tool]] to give curvatures to a selected object, if necessary. Select everything, go to the right side menu, in [Stroke] select [Advanced stroke settings], and then in the [Join] field select the type of finishing for the ends of the object.
![[Pasted image 20250121145818.png]]

Now making a break in the line (it's just a personal style).
Select the object press [Enter] key to Vector points, press [P] click 3 times on object (the last click between the first and two), press [V] key, press [Delete] key to delete the selected range.
![[Pasted image 20250121151209.png]]
  
And to soften the ends of the line break. Select the object, press the [Enter] key for Vector points, now select the two vector points at the ends, and in the right side menu, in [Stroke] select [Advanced Stroke Settings], in the [End points] field select how you prefer the finishing.
![[Pasted image 20250121151136.png]]

And finally, remove the restrictions from the created icon. To see how to remove restrictions go to [[2.1 - Frames]].

##### **Inputs**

Insert a rectangle and text, turn it into auto layout, configure auto layout. To configure auto layout, go to the right side menu, [Auto layout] define; [Dimensions] (Hug content) for adjust frame to content, [Direction], [Gap], [Alignment] and [Padding] to have the auto layout elements configured. Remembering that the fields mentioned above are for configuring the elements within the auto layout frame, in this case, the elements within the input field.
![[Pasted image 20250123145715.png]]
##### **Buttons**

Create a text with the name of the button, define the typography and color, then transform the text into auto layout, configure the auto layout similar to the inputs (remember to use multiples of 4 and 8), in the [Appearance] field define the [Corner radius]. Once this is done, press Ctrl + x and paste the button into your style guid, transform it into a component, and finally go to the component library and insert the button you just created. Then the button will look like below.
![[Pasted image 20250123205725.png]]

Create a secondary button. To do this, go to the style guide, select the button, and in the right side menu, in the [Buttons] field, click on the 3 dots (...), and then [Add variant], rename the layer (be very careful when renaming the layer, rename it in the [Button] field on the right side menu and then click on the [Select component] icon), modify the new button and rename it.
![[Pasted image 20250123210739.png]]
![[Pasted image 20250123212908.png]]

To use the new component in the design, make a copy of the main button in the design, and to switch to the other button, go to the right side menu, in the [Buttons] field, in [Property 1] select the second button.
![[Pasted image 20250123213710.png]]

*The height of a button must be between 44 and 48dp, which is recommended for touch pads, which considers the average size of a thumb so that it can have a good touch zone. This guarantees better usability for the user. Buttons that are too small can make usability difficult, while buttons that are too large can become an unwanted distraction.*

	KEYBOARD SHORTCUTS:
		  Ctrl + Alt + B => Detaches an object from its parent component.
		  Keep pressed Ctrl and click objects on component => To edit objects of a component separately.
		  Keep pressed Ctrl + Shift and click objects on component => To simultaneously edit several objects in a component.
		  Ctrl + Shift + 4 => Ativa/desativa grid.
