##### **Creating icons in Figma**

###### **Creating an eye icon**

Create a 24 x 24 frame.
Defines a name for the frame.
Create a 20 x 20 rectangle (0.5 stroke, center).
Create a circle, and copy the rectangle style with Ctrl + Alt + C and Ctrl + Alt + V.
Create a diagonal line with the P command, and then paste the same style as the rectangle. Make a copy of the line, rotate it 90º, and position it on the other diagonal.
Group elements with Ctrl + G.
Decrease the opacity of the element, use the shortcut {key 1}
Lock the layer of the created element. This grid is just a visual guide to help you create the icon.
![[Pasted image 20250114084120.png]]

Create an ellipse, center it, add stroke of 1, remove fill.
With the object selected press enter to open the vector properties. Move the vectors until the object takes the shape of an eye.
Create a circle. If you want, use the shortcut Shift + Alt to change the size of the circle from the center of the other element.
Now to insert one element inside another, open the vector points of the circle, select them and press Ctrl + X, press Esc, select the other element, open the vector points, and then press CTrl + V.
![[Pasted image 20250114085903.png]]

With the icon created, now hide the grid.
Constraints: for the object to scale along with the frame, in the right side menu, in {Constraints} set both fields (horizontal and vertical) to {Scale}.
Turn the object into a component press Ctrl + Alt + K.
Now this icon can maintain proportions when scaling. When you increase the size of the icon, you also increase the thickness of the border, the same for when you decrease the size.
![[Pasted image 20250114091250.png]]

	KEYBOARD SHORTCUTS:
		Shift + 0 => Zoom to 100%
		Shift + 2 => Centers all content to the center of the screen
		Ctrl + Alt + C e Ctrl + Alt + V => Copy element styles
		Ctrl + G => Groups elements
		1, 2, 3... => With an element selected, set its opacity.
