The [[Style guide]] is the reference source for all elements; colors, typography, components, etc. It is interesting to structure the style guide so that all the [[Visual assets]] created (colors, typography, etc.) are in one place. These assets can be accessed from any page in Figma.

To get started, download two plugins, Typography Styleguid and Color Style Guid.

Run Typography Styleguid. It will create a frame with all the previously configured typography, it is something more visual, if a developer wants something easier to visualize, for example.
![[Pasted image 20250115045909.png]]

Now create a header for the typography. To do this, create a frame above the typography frame, rename it to {Font}, create the text on the left with size {H4} and on the right with size {200}, position them in the frame following the [[Pixel Perfect]]. To facilitate positioning, do the following. With the object selected, press Alt, position the mouse over the frame, and use the arrow keys to move the object.
![[Pasted image 20250115053245.png]]

Run the Color Style Guid. It will also create a frame with all the previously created color settings. Something more casual too.
![[Pasted image 20250115050053.png]]

Next, create a frame for buttons below the color frame. 
To create a button, create text, type the name of the button, transform it into Auto Layout using the shortcut Shift + A, now, with the button selected in the right side menu in {Auto Layout - Alignment} define the text alignment to the center of the button.
![[Pasted image 20250115060358.png]]

Set the vertical padding to 16 and horizontal to 8.
![[Pasted image 20250115061347.png]]

Also define a text type for the button, as this type of text already exists in the library, just quickly double-click on the button text or Ctrl + click on the text and enter the button text type that is in the library.
![[Pasted image 20250115060739.png]]

Set a rounded corner to 24.
![[Pasted image 20250115061817.png]]
  
Add the button's background color, in the right side menu go to {Fill - Apply styles and variables}, then select the color.
![[Pasted image 20250115063111.png]]

Now rename the button layer in the left side menu. In this case, since the button is inside the buttons frame, just rename it to Primary. And finally, turn it into a component.
![[Pasted image 20250115063325.png]]

Note: it is not necessary to create the components before starting the design. Ideally, as you design and need to transform an object into a component, do so, and then bring the component into the style guide to make the project more organized.

	KEYBOARD SHORTCUTS:
		  Alt + keyboard arrows => Select the object, position the mouse over the frame, and use the arrow keys to move the object.
		  Shift + A = Transform into auto layout
