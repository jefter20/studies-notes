Design system is a set of patterns, components and guidelines that guide the development of interfaces, website or web system. With the aim of creating a visual and functional identity, in addition to facilitating the work of designers and developers.

The Design System guarantees the consistency and effectiveness of a digital product, and consequently, a better user experience.

Some advantages of the design system are: 

- Create an identity for the user
- Facilitate the work of designers and developers
- Ensure consistency and efficiency
- Maintain visual and functional cohesion over time
- Promote a balanced user experience

For the design system to be successful, it is important: 

- Create clear and accessible documentation
- Consider the needs of all stakeholders
- Create attractive and understandable formats, such as videos or tutorials
- Conduct collaborative workshops to create and review documentation
- Create a development-friendly design system
- Test documentation
