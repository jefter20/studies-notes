A Style guide is a set of rules for writing, formatting, and designing documents. It can also establish visual and interactive standards for a company's branding, content, and applications. 

What is included in a style guide?

- **Writing**
    
    Grammar, punctuation, tense, tone, wording, and writing best practices 
    
- **Design**
    
    Color palettes, typography, imagery, tone of voice, and other brand elements 
    
- **Usage**
    
    Specifications for how to use a logo, how to use colors, and how to use other brand elements 
    
- **User experience**
    
    Detailed direction on how to navigate and interact with a product or service 
    

Why is a style guide important? 

- It helps maintain brand recognition
- It helps build trust with audiences
- It helps reinforce brand values and messaging
- It helps ensure consistency across all platforms, markets, devices, and contexts

What is a style guide called? 

- A book-length style guide is often called a style manual or a manual of style (MoS or MOS)
- A short style guide is often called a style sheet
